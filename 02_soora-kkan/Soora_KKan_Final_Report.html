사내 팀 야유회 요리 경연을 위한 AI 멀티모달 비전 분석 및 팀장 맞춤형 평가 PWA 구축 결과보고서

프로젝트 명칭 SOORA-KKAN (수라깐 - 수라간 + 깐깐한 팀장) 개발 기간 2026.10
주요 기술 스택 React, Vite, Tailwind CSS, Gemini 2.5 Flash API 개발 방법론 Vibe Coding (AI 주도 점진적 코드 생성 및 배포)
배포 플랫폼 Vercel (PWA 모바일 웹 배포) 데이터 스토리지 Client-side LocalStorage (네트워크 독립성 확보)

1. 프로젝트 기획 의도 및 배경

사내 야유회에서 진행되는 조별 요리 경연대회는 팀원 간의 소통과 단합을 증진시키는 핵심 이벤트입니다. 기존의 주관적이고 단순한 수기 채점 방식을 탈피하여 스마트폰 기반의 공정하고 체계적인 심사 툴을 구축하고, AI 시각 분석과 위트 있는 심사위원 페르소나를 결합하여 행사 자체의 재미와 몰입도를 극대화하고자 기획되었습니다.

  • 네이밍 아이덴티티: 전통 궁중의 권위를 상징하는 '수라간'에 '깐깐한 팀장'의 시각을 결합하여 'SOORA-KKAN'으로 명명.
  • 모바일 최적화 (PWA): 별도 스토어 다운로드 없이 현장에서 스마트폰 홈 화면에 바로 설치하여 단일 앱 형태로 구동.
  • 오프라인 대응형 아키텍처: 야외 통신 불안정 환경에 대비하여 로컬 브라우저 저장소 연동 및 Dual Engine(Gemini API + 내장 휴리스틱 엔진) 구축.

3. Vibe Coding 단계별 개발 내역

1단계: 프로젝트 환경 구성 및 인터랙티브 UI 구축
  • Node.js v24 기반 Vite + React 프로젝트 생성 및 Tailwind CSS v4 스타일링 시스템 구축.
  • 초기 3초 인트로 스플래시 화면(회전 캐릭터 + 바운싱 타이틀) 및 고정형 엠블럼 헤더 개발.
  • 조 명칭, 출전 요리명, 조원 명단 입력과 10종 요리/캠핑 아이콘을 지원하는 조 등록 모달 구현.
2단계: AI 멀티모달 비전 연동 및 채점 시스템 완성
  • HTML5 capture="environment" 속성을 통한 스마트폰 카메라 즉각 촬영 및 갤러리 파일 업로더 구현.
  • Google AI Studio의 Gemini 2.5 Flash API 연동을 통한 사진 기반 시각 분석 및 구조화된 JSON 데이터 파싱.
  • 별점(★) 기반 5점 척도 터치 UI를 구현하여 현장에서 빠른 점수 입력 및 100점 만점 자동 가중치 계산.
  • canvas-confetti 라이브러리를 적용하여 1위 조 확인 시 축하 폭죽 애니메이션 연출.
3단계: 모바일 PWA 환경 최적화 및 Vercel 클라우드 배포
  • PWA 필수 규격 파일(manifest.json, sw.js 서비스 워커)을 절대 경로 기반으로 등록하여 안드로이드/iOS 홈 화면 추가 및 전체화면 구동 지원.
  • Vercel CLI를 통해 프로덕션 배포 완료 (https://02-soora-kkan.vercel.app).

4. 주요 트러블슈팅 및 해결 내역

  • Tailwind CSS v4 호환성 문제: Vite 8 환경에서 기존 PostCSS 설정 충돌 발생 → @tailwindcss/vite 공식 플러그인 도입으로 설정 간소화 및 해결.
  • Vite OXC 정규표현식 파싱 오류: JSON 마크다운 파싱 시 정규식 에러 발생 → replaceAll() 문자열 치환 방식으로 변경하여 안정성 확보.
  • PWA 홈 화면 실행 시 404 Not Found 오류: start_url 상대 경로 지정 문제 → 루트 절대 경로(/) 지정 및 서비스 워커 등록을 통해 모바일 설치 규격 완비.

5. 기대 효과 및 활용 계획

  • 현장 운영 편의성: 팀장이 스마트폰 하나로 사진 촬영, 평가, 순위 확인까지 원스톱으로 처리하여 대회 진행 시간 대폭 단축.
  • 팀원 참여도 및 흥미 유발: 단순 점수 발표를 넘어 AI가 분석한 세부 비주얼 분석과 유머러스한 심사평을 공유하여 축제 분위기 조성.
