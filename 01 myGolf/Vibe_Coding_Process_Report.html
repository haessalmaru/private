MyGolfNotes 바이브 코딩 프로세스 리포트

기획부터 PWA 모바일 패키징, 엑셀 연동 및 GitHub Pages 실전 배포까지

Author: Monk Studio
Date: 2026-09-06
Release: v1.0 (Public Live)
1. 프로젝트 기획 및 핵심 설계 사상

기존 골프 앱의 파편화된 기능(단순 스코어 카드 또는 복잡한 센서 장비)에서 벗어나, 부상 방지(허리/관절 부담 최소화), 상체 힘빼기, 지향 구질(드로우) 궤도 유지라는 골퍼 본연의 목적을 추적하기 위해 바이브 코딩(Vibe Coding) 방식으로 1인 웹 앱을 설계했습니다.

구분 채택 기술 및 사상 기획 의도
구동 형태 PWA (Progressive Web App) 앱스토어 등록 없이 홈 화면에 바로가기 설치, 전체화면 네이티브 구동
데이터 스토리지 Browser LocalStorage (JSON) 서버 구축 비용 0원, 오프라인(연습장 지하)에서도 완벽한 읽기/쓰기 보장
배포 환경 GitHub Pages (HTTPS 무료 호스팅) PC를 꺼두어도 365일 모바일에서 독립 작동하는 환경 구현
데이터 분석성 정형 Key-Value 구조 & CSV 내보내기 상관분석(통증 부위 vs 힘빼기 텐션) 및 캐시 삭제 시 안전 백업 보장
2. 단계별 구현 및 시행착오 가이드 (주의 & 체크 포인트)

[Step 1] UI 뼈대 및 연습 일지 로컬 저장 구축

  • 하단 탭 구조(일지/클럽/드릴)와 30분 단위 시간 칩, 다중 통증 부위 선택 로직 구축.
  • 다음 연습 시 반드시 상기할 Next-Action을 최상단 카드에 노출하는 피드백 루프 완성.
체크! 코드 수정 후 실시간 브라우저 확인 루틴 파일을 매번 새로 더블클릭하여 열 필요 없이, 브라우저 탭 하나를 띄워두고 VS Code에서 Ctrl + S(저장) ➔ 브라우저에서 F5(새로고침)만 누르면 즉시 반영됩니다. (VS Code 확장 Live Server 활용 시 자동 새로고침 지원)

[Step 2] 클럽 스펙 & 드릴 보관함 구현

  • 클럽별 스펙(샤프트, 로프트, 라이각, 토크) 등록 및 삭제 카드 UI.
  • 유튜브 드릴 원포인트 메모 및 딥링크(URL 바로가기) 연동.
주의! 자바스크립트 블록 괄호 계층 구조 이벤트 리스너 끝단 괄호(});) 안쪽에 다른 독립 기능 코드를 중첩해 붙여넣으면 구문 오류가 발생합니다. 서비스 워커 등 상위 글로벌 코드는 반드시 파일 최하단 완전히 바깥 블록에 독립 선언해야 안전합니다.

[Step 3] 모바일 Live Server 로컬 접속 디버깅

  • PC의 Live Server 포트(5500)를 동일 Wi-Fi 상의 스마트폰으로 접속 시도.
주의! 모바일 로컬 접속 시 발생하는 2대 허들
  1. 보안 연결 에러 (HTTPS 강제 전환): 모바일 브라우저 주소창이 IP 주소를 검색어로 인식하여 https://로 강제 리다이렉트하는 현상. ➔ 주소창 맨 앞에 http://를 명시적으로 직접 입력하여 해결.
  2. Cannot GET /myGolf/ 에러: 폴더명 불일치 현상. VS Code 상의 실제 경로가 01 myGolf처럼 공백/숫자가 포함된 경우, %20(공백 코드)을 넣거나 http://IP:5500 루트로 접속 후 폴더를 직접 클릭하여 해결.

[Step 4] 모바일 반응형 UI 보정 & PWA 환경 안착

주의! 스마트폰 기종별 하단 홈 바(제스처 바) 잘림 현상 기존 CSS의 100vh는 모바일 시스템 UI 영역을 고려하지 않아 하단 네비게이션 메뉴가 화면 아래로 밀려 잘립니다.
➔ height: 100dvh;(동적 뷰포트 높이)와 env(safe-area-inset-bottom)를 하단 패딩으로 확보하여 모바일 전 기종 완벽 안착.

[Step 5] 데이터 분석 요약 및 엑셀(CSV) 내보내기/백업

  • 상단 요약 카드: 총 연습 회차, 드로우 달성률(%), 허리 통증 빈도(%), 평균 텐션, 최빈 미스샷 트리거 실시간 계산.
  • 엑셀 CSV 내보내기 및 브라우저 캐시 삭제 대비 JSON 전체 백업/복원 기능.
체크! 엑셀 CSV 지수 표기(1.7886E+12) 및 한글 깨짐 방지
  1. 지수 표기 해결: 13자리 밀리초 ID 대신 index + 1(1회차, 2회차...) 순번으로 매핑 변경.
  2. 엑셀 한글 깨짐 해결: CSV 텍스트 맨 앞에 UTF-8 BOM 바이트(\uFEFF)를 결합하여 브라우저에서 다운로드하도록 설계.

[Step 6] GitHub Pages 배포 및 원격 동기화

  • PC가 꺼져도 작동하도록 GitHub Pages를 통한 24시간 상시 호스팅.
주의! 무료 계정 Pages 정책 및 Git 동기화(Sync) 누락
  1. Pages 메뉴 비활성화: 무료 플랜은 Private 저장소에서 Pages를 지원하지 않음. ➔ Settings ➔ General ➔ Danger Zone에서 `Make Public`으로 전환하여 해결. (개인 데이터는 깃허브가 아닌 스마트폰 로컬에 보관되므로 안전)
  2. 모바일 화면 미반영 (커밋 vs 푸시): 로컬에서 Commit만 하고 `Push (Sync Changes)`를 누르지 않으면 깃허브 서버로 코드가 넘어가지 않음. VS Code에서 푸시 후 Actions 탭에서 초록색 체크(✓) 완료를 확인해야 함.
3. 바이브 코딩(Vibe Coding) 핵심 교훈 및 인사이트
  1. 작은 단위의 실행 및 점진적 확인 (Iterative Loop): 방대한 코드를 한 번에 짜려 하지 않고, UI 뼈대 ➔ 폼 데이터 검증 ➔ 모바일 연결 ➔ 배포 ➔ 분석 고도화 순으로 한 번에 한 단계씩 동작을 눈으로 보며 조율할 때 디버깅이 가장 쉽습니다.
  2. 정형화된 데이터 설계의 힘: 첫 단추에서 통증, 구질, 텐션을 문자열 덩어리가 아닌 정형 Key-Value 구조로 설계해 두었기 때문에, 추후 대시보드 통계 계산과 엑셀 추출 기능을 10분 만에 얹을 수 있었습니다.
  3. 완전 독립형 아키텍처: 별도의 유료 클라우드 DB 없이도 LocalStorage + GitHub Pages + PWA 조합을 활용하면, 비용 0원으로 언제 어디서나 오프라인 구동이 가능한 개인 최적화 도구를 완성할 수 있습니다.
