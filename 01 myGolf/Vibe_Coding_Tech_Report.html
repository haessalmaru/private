MyGolfNotes 시스템 아키텍처 및 바이브 코딩 기술 리포트

작성자: Monk Studio · 프로젝트: MyGolfNotes (v1.3) · 호스팅: GitHub Pages

1. '바이브 코딩(Vibe Coding)'의 정의와 개발 패러다임

바이브 코딩은 특정 프로그래밍 언어(C, Python, Java 등)를 지칭하는 명칭이 아니며, 사람이 자연어로 문제 정의와 기능의 '느낌(Vibe)'을 지시하고, AI(Gemini)가 실제 코딩과 버그 픽스를 수행하는 최신 AI 페어 프로그래밍(Pair Programming) 개발 방식을 의미합니다.

💡 핵심 커뮤니케이션 요약 (누군가 질문했을 때의 답변 가이드):
"바이브 코딩 방식으로 AI(Gemini)와 대화하며 기획·구현했고, 기술 스택은 웹 표준 언어인 HTML, CSS, JavaScript 기반의 독립형 PWA(프로그레시브 웹 앱)입니다."

2. 프로젝트 파일 구성 및 시스템 아키텍처

파일명 기반 언어 핵심 기능 및 시스템 내 역할
index.html HTML5 앱의 골격(UI 뼈대): 일지 탭, 클럽 22필드 피팅 폼, 드릴 검색 바, 모달 팝업의 위치와 레이아웃 구조 정의
style.css CSS3 외관 및 반응형 디자인: 다크 모드(#121212), 미스샷 2열/4열 그리드 배치, 모달 슬라이드업 애니메이션, 모바일 안전영역 대응
app.js JavaScript (ES6+) 앱의 두뇌(비즈니스 로직): 9대 미스샷 팝업 제어, LocalStorage 데이터 CRUD, 월간 달력 파싱 및 5대 구질/통증 통계 계산, CSV 추출
manifest.json JSON 앱 설치 명세서: 모바일 브라우저에서 '홈 화면에 추가' 시 독립형 네이티브 앱(PWA)처럼 전체 화면으로 구동되도록 아이콘과 테마 지정
sw.js Service Worker 오프라인 캐시 엔진: 네트워크 연결이 취약한 지하 타석에서도 구동되도록 리소스를 캐싱하고 버전 업데이트(v1.3 등) 시 자동 동기화
GOLF_APP_PRD.md Markdown 제품 기획서(PRD): 타깃 사용자, 부상 방지 및 힘빼기 핵심 요구사항, 릴리즈 로드맵을 기록한 마스터 설계 문서

3. MyGolfNotes의 기술적 특장점

Zero Backend Architecture: 서버 유지 비용 없이 GitHub Pages 무료 정적 호스팅과 브라우저 LocalStorage만으로 완벽한 데이터 영속성 유지
데이터 주권 및 안전성: 개인 연습 일지 및 클럽 피팅 제원을 언제든 Excel 호환 UTF-8 BOM CSV 파일로 즉시 내보내기 가능
Mobile First PWA: 별도 앱스토어 심사나 결제 없이 URL 하나로 모든 기기(스마트폰, 태블릿, PC)에서 네이티브 앱과 동일하게 사용
