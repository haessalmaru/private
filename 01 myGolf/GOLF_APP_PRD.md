# [PRD] 개인 맞춤형 골프 연습 관리 및 스윙 분석 PWA (MyGolfNotes)

## 1. 프로젝트 개요 (Overview)
- **목적:** 연습 전 핵심 과제 상기(Intent-setting), 연습 중/후 신체 컨디션(통증 모니터링, 힘빼기) 및 구질/미스샷 분석, 장비 스펙 관리, 드릴 영상 아카이빙을 통합 제공하는 1인용 골프 코칭 웹 앱.
- **주요 사용자 환경:** 모바일 브라우저(Safari/Chrome) 접속 후 '홈 화면에 추가(PWA)'하여 네이티브 앱처럼 사용.
- **핵심 기술 스택:** HTML5, CSS3(모바일 뷰포트 반응형), Modern JavaScript (ES6+), LocalStorage (영구 데이터 보관).
- **무결점 원칙:** 외부 백엔드 서버나 복잡한 패키지 의존성을 배제하고 브라우저 샌드박스 내부에서 100% 자급 구동되도록 단일 구조화.

## 2. 데이터 계층 및 입력 스키마 (Data Taxonomy)

### 탭 1: 연습 일지 (Practice Log)
1. **연습 전 (Check-in)**
   - **지난번 핵심 과제(Previous Next Action):** 직전 기록 자동 팝업
   - **오늘의 One-Thing (집중 과제 1개 선택):**
     - 예: [상체 힘빼기(텐션 3이하 유지)], [왼발 디딤 후 부드러운 힙턴], [원피스 테이크웨이], [임팩트 머리 고정]
   - **사전 컨디션 체크:** 현재 통증 유무 및 피로도 상태

2. **연습 후 (Check-out)**
   - **연습 시간 (30분 단위 드롭다운/버튼):**
     - [30분] / [60분] / [90분] / [120분] / [120분 이상]
   - **신체 통증 및 피로도 모니터링 (선택형 칩 & 강도):**
     - **통증 부위 (복수 선택 가능):** [허리/요추], [왼쪽 손목], [오른쪽 팔꿈치], [왼쪽 어깨], [갈비뼈/늑골], [목], [무릎/발목], [이상 없음]
     - **통증 정도 (선택):** [0: 전혀 없음] / [1: 가벼운 뻐근함] / [2: 샷할 때 불편함] / [3: 휴식 필요/통증 큼]
   - **연습 클럽 다중 선택:** 드라이버, 우드, 유틸, 롱아이언, 미들아이언, 숏아이언, 웨지
   - **주요 구질 분포 (원클릭 버튼):**
     - 목표: 드로우 지향
     - 실제 결과 비율 선택: [드로우 70% 이상] / [스트레이트/약드로우] / [푸시 발생] / [훅/풀훅 발생] / [슬라이스]
   - **스윙 메커니즘 정밀 체크포인트 (드롭다운 & 슬라이더):**
     - 상체 힘빼기 정도 (1~5 레벨)
     - 체중이동 방식 (자연스러운 힙턴 / 오른발에 남음 / 과도한 슬라이드)
     - 테이크백 & 손목 (바른 궤도 / 얼리 코킹 / 과도한 힌징)
   - **미스샷 원인 자가 진단 (체크박스/칩 선택):**
     - 쪼루/탑볼, 생크, 뒤땅 발생 시 주요 원인 매핑:
       - [급한 템포(트랜지션 빠름)]
       - [배치기(얼리익스텐션)]
       - [체중이 우측에 남음]
       - [그립 악력 과다]
       - [헤드업/시선 분산]
   - **다음 연습 One-Thing (단 하나의 교정 과제):** 텍스트 한 줄 작성

### 탭 2: 마이 클럽 스펙 (My Gear Specs)
- 클럽 목록 (Driver, Wood, Utility, Iron 4~P, Wedges)
- 입력 필드:
  - 브랜드/모델명, 샤프트 모델 및 플렉스(Flex)
  - 로프트각(°), 라이각(°), 샤프트 무게(g), 토크값(Torque), 스윙웨이트(D0~D3 등)

### 탭 3: 드릴 & 레슨 보관함 (Drills & Links)
- 항목 구성:
  - 카테고리 태그: [허리 부담 없는 스윙], [힘빼기/템포], [드로우 구질 드릴], [테이크백 교정], [체중이동]
  - 레슨 제목, 유튜브 링크(URL), 핵심 요약 메모 1줄
  - 클릭 시 바로 모바일 유튜브 앱 또는 인앱 플레이어 호출

## 3. 화면 UI/UX 구조 (Mobile-First Layout)
- **상단 바:** 앱 타이틀, 최근 연습 날짜, 신체 통증 상태 배지
- **하단 고정 내비게이션 바 (Bottom Navigation):**
  - 📝 **[연습 일지]**
  - 🏌️ **[클럽 스펙]**
  - 📺 **[레슨 드릴]**
  - 📊 **[통계/복기]** (최근 5회 구질, 통증 부위 빈도 요약)
- **카드형 컴포넌트:** 작은 모바일 화면에서도 엄지손가락으로 쉽게 누를 수 있는 최소 44px 터치 영역 보장

## 4. 단계별 구현 로드맵 (Git Commit Milestones)

### Phase 1: 기본 UI 프레임워크 및 모바일 레이아웃 구축
- **Step 1-1:** 모바일 뷰포트 메타태그와 하단 내비게이션 탭 바 레이아웃 작성 (`index.html`, `style.css`)
- **Step 1-2:** 탭 전환 자바스크립트 로직 구현 (`app.js`)
- 📌 **Commit 1:** `feat: 모바일 반응형 탭 레이아웃 및 뷰포트 기본 UI 구현`

### Phase 2: 연습 일지 입력 폼 및 로컬스토리지 영구 저장
- **Step 2-1:** 연습 시간(30분 단위), 통증 부위 및 통증 레벨 선택 UI 배치
- **Step 2-2:** 연습 전/후 체크리스트(힘빼기 레벨, 구질 선택, 미스샷 칩) UI 배치
- **Step 2-3:** LocalStorage 입출력 모듈 작성 (새로고침/재시작해도 데이터 유지)
- **Step 2-4:** 직전 연습의 "Next Action"을 상단에 자동 호출하는 피드백 루프 구현
- 📌 **Commit 2:** `feat: 통증 모니터링 및 스윙 체크리스트 일지 로컬 저장 기능 추가`

### Phase 3: 클럽 스펙 관리 및 드릴 아카이브
- **Step 3-1:** 클럽별 스펙(라이각, 토크, 샤프트 등) 카드 등록/수정/삭제 폼 구현
- **Step 3-2:** 드릴 영상 링크 등록 및 클릭 시 유튜브 연동 카드 컴포넌트 추가
- 📌 **Commit 3:** `feat: 클럽 스펙 및 드릴 링크 아카이브 기능 구현`

### Phase 4: 모바일 PWA 패키징 및 오프라인 구동 최적화
- **Step 4-1:** `manifest.json` 및 앱 아이콘 설정 (홈 화면 추가 시 주소창 없는 전체 화면 실행)
- **Step 4-2:** 오프라인 캐싱 서비스 워커(`sw.js`) 등록 (연습장 지하 등 네트워크 불안정 시 완벽 구동)
- 📌 **Commit 4:** `feat: PWA 설정 완료 및 오프라인 구동 환경 구축`
